MQTT message reference

Receive-only UR3e joint telemetry. Use this format when integrating a telemetry receiver.

Topic
/rover/joints

Send a JSON object with numeric joint angles in radians. The keys run from base (j1) through wrist 3 (j6).

{
  "j1": 0,
  "j2": -1.5708,
  "j3": 1.6581,
  "j4": -1.6581,
  "j5": -1.5708,
  "j6": 0
}
